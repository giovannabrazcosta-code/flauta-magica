# Sons (não incluídos)

Os arquivos `.wav` não estão neste repositório (são grandes, 130 MB só os 14 usados, e parte deles vem de um
repositório de terceiros). Para usar as simulações em Java e JavaScript, coloque nesta pasta os 14 arquivos abaixo.

| Faixa do cartão SD | Arquivo |
|---|---|
| 1 | `AG 1 esc 1.wav` |
| 2 | `AG 1 INVERS 3.wav` |
| 3 | `AGU 3.wav` |
| 4 | `AGU 4.wav` |
| 5 | `AGUDO 5.5.wav` |
| 6 | `AG 1 INVERS 1.wav` |
| 7 | `AG 1 INVERS 2.wav` |
| 8 | `AG 1 INVERS 5.wav` |
| 9 | `AG 6.wav` |
| 10 | `AGUDO 6.wav` |
| 12 | `R 1.wav` |
| 13 | `R 2.wav` |
| 14 | `R 3.wav` |
| 15 | `R 3 (1).wav` |

Essa correspondência é uma **suposição**: o firmware só guarda o número da faixa. As faixas 11 e 16 não têm arquivo associado.
